# 小伙伴头像重新验收 · 2026-09-09

**第二轮结论：浏览器已测项 7 个通过、2 个失败；九个头像的真机触摸均未验证，整体尚未全部通过。** 鲸鱼、鲨鱼仍未满足实际 48px 下脸部清楚的 A2，连带 A6 失败。头像与模型一致性、圆形取景、视觉大小，以及选择器焦点、滚动和选择操作均通过本轮浏览器检查。

本轮在用户确认伙伴修复完成后，重新检查全部九个头像。验收依据为 [PRODUCT 的 A1–A8](../PRODUCT.md#小伙伴头像验收标准)，包含头像图像、焦点、滚动及选择交互。模型仅用于核对头像身份和选择结果。本轮仅更新验收记录与证据，未修改生产代码、头像或模型。[上一轮报告](INITIAL-REPORT.md)保留为历史记录，其旧结论不适用于当前版本。

## 条件与证据

- macOS / Codex 内置 Chromium，当前 WebGPU 页面；默认软胶、默认颜色、无饰品正面模型。
- 实际浏览器视口：桌面 1440×1000、手机布局 390×844、窄屏 320×740，无页面缩放操作；通过 `innerWidth/innerHeight` 核实，未使用 iframe 代替。320px 是本次检查条件，不新增产品支持下限。
- 每项按钮为 64×64 CSS px，头像区域为 48×48 CSS px。当前图片使用 `object-fit: contain`、无缩放变换；九张源图均为 512×512。原图及页面最终圆形呈现均已检查。
- 每个伙伴均保留三个视口的选中截图；切换到相邻伙伴时，同时检查其未选中状态。九项均正常显示，无空白、破图或状态装饰遮脸。
- [输入指纹](recheck-2/source-sha256.txt)覆盖九张头像、选择器 CSS/组件及角色源码。取证结束校验全部匹配，期间头像相关输入未变化；工作区其他任务的提交不作为通过证据。
- [运行检查数据](recheck-2/checks.json)记录 27 个逐项选择状态及两次横滚状态，包括视口、页面宽度、按钮位置、图片加载/样式、选中伙伴及实际场景伙伴。静态图片由独立代理复核，见[独立视觉记录](recheck-2/independent-review.md)。数值及原图均未替代实际尺寸视觉判断。

## 选择器操作结果

- 桌面逐个鼠标点击九项：头像选中标记、名称与实际 WebGPU 场景伙伴一致。
- 390px 视口通过实际 Tab 依次到达九项，核对每项可访问名称；使用 Enter 选择，金鱼/鲸鱼/鲨鱼使用 Space 选择。320px 再逐项 Enter 选择。所有结果对应正确，当前按钮完整可见。
- 首项、中间项、末项的键盘焦点外圈完整；旧的首尾焦点裁切问题关闭。另用 Shift+Tab 保持螃蟹已选、将焦点移到海龟，确认焦点外圈与选中底色/勾选可区分，见[未选中焦点截图](recheck-2/narrow-focus-unselected.png)。
- 390px 实际横滚可到首尾，见[列表起点](recheck-2/mobile-scroll-start.png)和[列表终点](recheck-2/mobile-scroll-end.png)。选择后自动让当前项可见；手动滚动查看其他项时允许已选项暂时离开视区。
- 三个视口均无整页横向溢出，移动视口列表内部滚动正常，按钮保持尺寸。未出现滚动后误切换的浏览器指针现象；此结果不代替真机触摸。

## 剩余问题与验收边界

1. **鲸鱼、鲨鱼 A2/A6 失败：** 后续需改善实际 48px 下眼口的辨识度，同时继续满足 A1 的模型一致性；不能用放大截图或只认出物种作为通过依据。修改后按相同三个视口复验；若改共享头像尺寸或裁切样式，须复查全部九项。本轮未执行修复。
2. **真机触摸未验证：** 九项均缺少真实手机上的触摸滑动、点选和滑动不误触证据；视口模拟与桌面指针不替代它。
3. 未扩展到模型本体、物理、饰品、其他页面或跨浏览器完整验收。构建、类型检查和物理测试不适用于本轮仅证据与报告的改动。
