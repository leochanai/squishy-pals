# 界面打磨实施结果

2026-09-10，用户明确“开始修改”后，将审查方案应用到本地开发版本。

## 已应用的取舍

- 首页删除眉题、装饰圆点和重复的伙伴数量邀请；保留品牌、主标题、说明、主按钮及演示素材。
- 玩法区改为奶油底上的三步排列，用「玩法演示」替代口号；保留步骤点击、播放与暂停，选中和悬停使用浅绿反馈。
- 图鉴删除编号、重复引导与箭头底座，只保留一次伙伴数量；九位伙伴的完整肖像、名称、具体玩法和整卡入口保留。悬停只轻微缩放肖像，继续支持 reduced-motion。
- 站内前进、进入设置、返回图鉴的箭头方向统一。
- 手机「全部摘下」「回到捏玩」点击区域高度增至 44px；原有文字大小保留。
- 移除试玩状态装饰圆点，保留 live region；仅修改状态文本和参数描述，没有改变物理、材质、参数映射或恢复逻辑。
- DESIGN.md 仅同步图鉴悬停反馈的实际契约。
