## 设计简报

- 判断优先级：布局与核心操作成立 → 主体有充分空间 → 视觉质量 → 局部装饰。
- 明快、有触感的玩具游乐场。亮黄绿、橘红、深色文字形成明确身份；真实角色展示，不以静态图假冒3D操作。
- 首页：大角色、直接试玩入口、图鉴入口、最少玩法说明。
- 图鉴：快速辨识与挑选九位伙伴，避免冗长重复卡片。
- 试玩：舞台充分使用窗口，工具按需展开；手机底部工具抽屉。画布可用空间与主体显示比例分别核查。
- 顺序：首页 → 图鉴 → 试玩 → 全路径复核。单页主动重设计、单页独立评论，不合并评分。
- 不引用外部专业参考图。新增/改写文案待人工逐行审核；无新增疗效、性能或持久化承诺。
