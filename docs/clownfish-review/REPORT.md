# 小丑鱼新增与验证 · 2026-09-10

新增 `clownmochi`（橙橙小丑鱼）：独立身体几何、三道环身白带、黑色鳍缘、单尾以及七个可抓鱼鳍。沿用既有软体求解器模式、材质和饰品机制；不改变金鱼实现。图鉴和正面头像直接导出真实模型画布，不使用另一个造型的插画。

## 形态依据与必验视角

**需要侧面。** 头部拖动会显露两侧，三道条纹、单尾和背鳍需要侧面才能完整辨识。必验正面、左侧、右侧。

依据 [佛罗里达自然历史博物馆眼斑双锯鱼资料及实拍](https://www.floridamuseum.ufl.edu/discover-fish/species-profiles/clown-anemonefish/)、[蒙特雷湾水族馆](https://www.montereybayaquarium.org/animals-the-ocean/animals-a-to-z/clownfish) 和 [夏威夷大学鱼类解剖](https://www.manoa.hawaii.edu/exploringourfluidearth/biological/fish/structure-and-function-fish)。侧面照片支持三带位置、单圆扇尾及鳍缘判断；正面成对胸鳍、左右眼和口部位置依据形态资料作萌化解释，不声称照片级还原。

| 项目 | 初次差异 | 修复及复查 |
| --- | --- | --- |
| 白带 | 正面阶梯状锯齿 | 球体经纬方向沿身体纵轴，颜色边界平滑过渡；[正面](front.png)、[左侧](left.png)、[右侧](right.png)复查，无原有明显阶梯 |
| 背鳍 | 扇形末端悬空，侧面像独立叶片 | 底边沿背部曲面贴合；三视角复查通过 |
| 眼镜、帽子 | 镜圈内缘被脸遮挡，背鳍穿过帽顶 | 小丑鱼专用镜圈前移、帽子移至前额；[正面](accessories.png)、[侧面](accessories-side.png)复查 |
| 图鉴和头像 | 内置截图裁切的比例异常，混入检查按钮 | 改为实际 WebGPU canvas 的 PNG 导出；独立评审从图鉴与试玩页复查，均为纯角色图 |

模型证据使用真实内置浏览器 WebGPU，640×640 画布，沿用生产 `createLighting`、摄影棚环境、ACES、曝光 0.98。基础相机 `(0, 3.3, 8.5)` 看向 `(0, 1.35, 0)`，正面/肖像导出有取景放大。测试用视角按钮没有加入产品页面。

## 交互与兼容

- 正面及两侧分别检查按压、身体拉扯、尾鳍拉扯、释放和戳动；白带与身体同场形变，未观察到网格破裂或五官脱离。证据：[正面按压](front-press.png)、[正面身体](body-drag.png)、[正面尾鳍](front-tail.png)、[左侧按压](left-press.png)、[左侧身体](left-body.png)、[左侧尾鳍](tail-drag.png)、[左侧戳动](left-poke.png)、[右侧按压](right-press.png)、[右侧身体](right-body.png)、[右侧尾鳍](right-tail.png)、[右侧戳动](right-poke.png)。检查画布不含生产取景约束，拖拽中局部可能出画；生产边界另由 stage 测试覆盖。
- [果冻](jelly.png)和[机械](mechanical.png)实际渲染正常，配色保留白带和鳍缘；颜色、软硬、阻尼、材质缓存、资源释放已纳入原测试矩阵。
- 独立 Agent 从真实图鉴入口复核：选中、模型与路径一致；鼠标捏拉释放及戳动有反馈；三材质、粉/绿配色、帽子与蝴蝶结双向互斥、耳机和眼镜、切金鱼再回小丑鱼均通过。恢复原状从绿+机械+蝴蝶结恢复橙+软胶+无饰品及正面。
- 生产界面：桌面 1280×720、手机 390×844、窄屏 320×720；窄屏设置展开后仍能看到模型。320px 时页面 scrollWidth=320，没有整页横向溢出。
