# 角色逐图优化进度

目标：以 `public/pals/` 对应图片为依据，逐个改进交互模型的轮廓、比例、五官、材质和观察角度。用户明确允许侧面、四分之三侧面，不要求全部正面。禁止通过更换参考图片来规避模型差距。整体目标仍在进行中。

## 2026-09-07 第一轮

- 鲸鱼：独立 `whalemochi.ts`，用横向连续截面重做宽头、圆肚与抬起的尾柄；一体分色腹部、侧眼、长笑线、厚胸鳍和水平双叶尾。观察相机降低至侧上方。Chrome 实际渲染已与鲸鱼图片比较；不再是正面的椭圆鱼。按压、拖拽、释放、弹跳、参数极值、重置和释放资源测试通过。
- 鲨鱼：独立 `sharkmochi.ts`，采用向右的侧面、尖吻、侧眼、三条鳃缝、白腹、三角背鳍和竖直分叉尾。鱼鳍使用椭圆截面形成圆润实体，替换会出现平板硬边的挤出几何。Chrome 实际渲染已与鲨鱼图片比较；物理测试通过。
- 原 `oceanmochi.ts` 的简化共享外形已替换、移除。
- 新增模型三角面朝外的有向体积校验，避免“测试通过但渲染穿透”；身体拾取测试避开鲨鱼背鳍，并断言身体句柄。
