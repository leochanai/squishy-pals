# 鲸鱼眼部与头像独立复验

复验范围：只读检查主代理在内置浏览器保存的实际渲染截图，以及九张 `public/pals/*-front.png` 原图；本复验者未参与鲸鱼眼部或头像实现。本文件不将截图复核写成重新操作过浏览器，也不以截图代替完整交互验收。

依据：`docs/PRODUCT.md` 的「新增伙伴成功标准」第 4 条及「小伙伴头像验收标准」A1–A7。手机截图左侧分别是 390／320 CSS px 的实际 iframe 产品视口；右侧灰色区域属于截图宿主，未计为产品留白或横向溢出。`avatar-checks.json` 记录两种视口下按钮均为 64×64，文档 scrollWidth 与视口相同；部分普通截图发生垂直滚动，不能拿截图中的 top 坐标与记录值直接相减判断布局错误。

## 鲸鱼右眼脱离回归

旧图 [whalemochi-front-poke.png](whalemochi-front-poke.png) 中，画面右眼与身体之间存在明显背景色间隙，属于真实的眼部脱离。

| 软胶 | 通过，三帧双眼均紧贴体缘，无旧图右侧空隙 | 通过，近侧眼随头部压缩和伸展，无漂浮 | 通过，近侧眼随头部压缩和伸展，无漂浮 |
