# 静态测试覆盖边界（2026-09-09）

依据：docs/PRODUCT.md「新增伙伴成功标准」、docs/ARCHITECTURE.md、docs/QUALITY-GATES.md，以及各 scripts/test-*.ts。

现有全部测试使用 Node，不创建 Renderer；不能替代实际 WebGPU、浏览器路由、输入、触屏、形态照片对照、图鉴封面和缩略图一致性验收。

| 检查 | 实际覆盖 | 缺口 |
| --- | --- | --- |
| test:physics | 八爪鱼软/机械，墨鱼、鱿鱼、金鱼、鲸鱼、鲨鱼的数值物理、按压/拖动/释放/重置 | 无真实输入/GPU；不含沿海三伙伴，另由 coastal 覆盖 |
| test:coastal | 海豹/海龟/螃蟹按压、身体和一个代表附肢、专属动作、三材质、眼镜+帽子、边界和左右转头 | 仅一个代表附肢；软硬/阻尼只检查四极端稳定性，无效果强度差异；未断言颜色实际改变；无全饰品组合/材质资源逐次释放断言 |
| test:stage | 原六伙伴及机械八爪鱼数值取景和边缘约束 | 三沿海伙伴由 coastal 另验；无真实页面尺寸/遮挡/触屏 |
| test:parameters | 原六伙伴及机械八爪鱼软硬/阻尼效果对比 | 不含沿海三伙伴 |

| test:materials | 原六伙伴及机械八爪鱼材质/颜色/姿态/资源释放，注册八爪鱼结构切换 | 不含沿海三伙伴的同等详尽材质/颜色/释放断言 |

| typecheck/lint/build | 类型、静态、构建链 | 不证明运行体验和形态正确 |

所有 Node 通过仍只能记为对应内部检查通过。产品六条新增伙伴标准中的真实照片与逐视角形态、真实交互、图鉴/缩略图一致性、桌面和手机可操作性须以主任务实际运行证据为准。
