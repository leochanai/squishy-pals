## 已知视觉限制与文案人工审核

八爪鱼腕足的碎白边来自吸盘与身体相交；只读诊断发现首腕58–76%的吸盘环顶点位于身体内部。材质与光照差异也是既有图鉴资源问题。本轮不模糊图片、不隐藏难看部位，不将它们报为已修复。

待人工逐行审核：首页新标题与说明、主入口“挑一位小伙伴”、三组动作提示、图鉴“一起玩”、试玩设置标题与操作提示、九角色精简描述。均基于已有玩法，无新增性能、疗效、客户或保存承诺；模型生成文案不等于人工审稿。

复用规则：深紫用于主要行动和选择，角色浅色用于图鉴底色；中文名称优先、英文辅助；桌面三列／平板两列／手机单列；试玩平板和手机设置置于舞台下；圆形头像保留物种轮廓；不裁剪真实画布来放大模型；按钮和画布保留键盘焦点；减少动态偏好时关闭CSS装饰动效。
